

# 📘 Neural Network Training Essentials

## 🔹 Activation Functions
Activation functions introduce **non-linearity** so networks can learn complex patterns.

| Function | Formula | Output Range | Use Case |
|-----------|----------|---------------|-----------|
| **Sigmoid** | \(f(z) = \frac{1}{1 + e^{-z}}\) | (0, 1) | Binary classification |
| **ReLU** | \(f(z) = \max(0, z)\) | [0, ∞) | Deep networks (fast training) |
| **Tanh** | \(f(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}\) | (-1, 1) | Hidden layers |
| **Softmax** | \(f(z_i) = \frac{e^{z_i}}{\sum e^{z_j}}\) | (0, 1) | Multi-class classification |

👉 Without activation functions, a neural network would behave like simple linear regression.

---

## 📉 Gradient Descent
Gradient Descent is the optimization algorithm that updates weights to minimize error.

**Formula:**
\[
w := w - \eta \frac{\partial L}{\partial w}
\]

- \(w\) = weight  
- \(\eta\) = learning rate (step size)  
- \(\frac{\partial L}{\partial w}\) = gradient (slope of loss function)

**Types:**
- **Batch Gradient Descent** → uses all data at once.  
- **Stochastic Gradient Descent (SGD)** → updates after each sample.  
- **Mini-Batch Gradient Descent** → updates after small batches (most common).

---

## 🔁 Epoch
An **epoch** = one complete pass through the entire dataset.

**Example:**  
- Dataset = 100 samples, batch size = 10.  
- One epoch = 10 updates.  
- Training for 50 epochs → model sees dataset 50 times.

👉 Too few epochs → underfitting.  
👉 Too many epochs → overfitting.

---

## ⚠️ Vanishing Gradient Problem
- In deep networks with Sigmoid/Tanh, gradients shrink as they backpropagate.  
- Example: derivative ≈ 0.25 → after 5 layers: \((0.25)^5 = 0.00098\).  
- Early layers stop learning → model stuck giving same outputs.  

**Fixes:**
- Use **ReLU/Leaky ReLU**.  
- Apply **Batch Normalization**.  
- Add **Residual Connections (ResNet)**.  
- Use **Xavier/He initialization**.

---

## ✅ Training Loop Summary
```text
Forward Propagation → Activation Function → Output
↓
Compute Loss
↓
Backward Propagation → Gradient Descent → Update Weights
↓
Repeat for many Epochs
↓
Watch out for Vanishing Gradients
```
